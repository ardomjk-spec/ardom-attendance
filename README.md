# ARDOM Attendance

Face-verified attendance web app (PWA) — hosted free on GitHub Pages.

**Live site:** https://ardomjk-spec.github.io/ardom-attendance/

This repo is the published copy only. The editable source lives outside this repo
(local project folder). To publish an update: copy the 6 files
(`index.html · styles.css · app.js · config.js · sw.js · manifest.json`) here,
commit, push — Pages rebuilds automatically.
